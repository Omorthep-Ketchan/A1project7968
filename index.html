Course Assignment

CS100 A1: My First Learning Portfolio

ช่วงเวลา: สิงหาคม 2569 | บทบาท: Individual Developer

พัฒนาเว็บไซต์ Learning Portfolio หน้าแรกของตนเอง โดยเริ่มต้นเขียนโค้ดตั้งแต่ศูนย์ด้วย HTML และ CSS เพื่อฝึกการวางโครงสร้างเว็บและการจัดสไตล์

ทักษะที่เกี่ยวข้อง: HTML5, CSS3, Semantic HTML, Live Server

Reflection

• What I did: ออกแบบและเขียนหน้าเว็บพอร์ตโฟลิโอหน้าเดียว เชื่อมโยงส่วนต่างๆ และอธิบายการทำงานของ Client/Server

• What I learned: เข้าใจโครงสร้าง Box Model พื้นฐาน รวมถึงบทบาทของเบราว์เซอร์ในการอ่านโค้ด

• Challenge: ช่วงแรกจำพวก Property CSS ไม่ค่อยได้ และสับสนเรื่อง Relative Path ของไฟล์รูปภาพ ต้องคอยเปิดหาและทดสอบเรื่อยๆ

• Next step: อยากปรับหน้าเว็บให้รองรับการเปิดบนมือถือได้ดีขึ้น และทำงานร่วมกับ CSS Framework

Competition

การแข่งขันหุ่นยนต์ระดับกลาง ม.4 - 6 งานศิลปหัตถกรรมนักเรียน ครั้งที่ 70

ช่วงเวลา: 24 - 25 ตุลาคม 2565 | บทบาท: สมาชิกทีม (โรงเรียนแก่งคอย)

เข้าร่วมการแข่งขันหุ่นยนต์ระดับกลาง ระดับเขตพื้นที่การศึกษา (สพม.สระบุรี) ได้รับรางวัลเหรียญทอง รองชนะเลิศอันดับ 1 โดยร่วมมือกับเพื่อนในทีมออกแบบ ประกอบโครงสร้าง และปรับแต่งระบบควบคุมหุ่นยนต์เพื่อทำภารกิจตามโจทย์

ทักษะที่เกี่ยวข้อง: Robotics, Problem Solving, Teamwork, Control Logic

Reflection

• What I did: ร่วมกับทีมออกแบบโครงสร้างกลไกหุ่นยนต์ ทดสอบระบบควบคุมเซนเซอร์ และแก้ไขจุดบกพร่องระหว่างซ้อม

• What I learned: ได้เข้าใจการทำงานประสานกันของฮาร์ดแวร์และตรรกะคำสั่ง รวมถึงการสื่อสารและแบ่งหน้าที่กันในทีมภายใต้เวลาจำกัด

• Challenge: สภาพสนามแข่งขันจริงมีแสงและพื้นผิวต่างจากที่ซ้อม ทำให้เซนเซอร์อ่านค่าคลาดเคลื่อน ต้องช่วยกันปรับจูนค่าหน้างานเพื่อแก้ปัญหาเฉพาะหน้า

• Next step: นำพื้นฐานการคิดเชิงตรรกะและการแก้ไขปัญหาเชิงระบบจากการแข่งหุ่นยนต์มาต่อยอดกับการเขียนโค้ดและพัฒนาเว็บในระดับมหาวิทยาลัย
