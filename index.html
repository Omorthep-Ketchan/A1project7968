What I Built

เว็บนี้เป็นเว็บ First Learning Portfolio ของผมครับ มีส่วนประกอบหลักๆ คือ:

  • ส่วนหัว : แถบสีชมพูด้านบน พร้อมเมนูแบบ Responsive
  • About Me : ข้อมูลส่วนตัวและงานอดิเรก
  • What I Built : โครงสร้างและแนวคิด Client/Server
  • How I Built : ขั้นตอนและเครื่องมือที่ใช้พัฒนา

เรื่อง Client กับ Server มีเกิดขึ้นไหม?

มีเกิดขึ้นทั้งคู่ครับ ถึงจะเปิดดูในเครื่องตัวเองก็ตาม เพราะว่า

Client

เว็บเบราว์เซอร์อย่าง Edge หรือ Chrome ที่ผมใช้เปิดดูหน้าเว็บ เป็นตัวคอยอ่านโค้ด HTML กับ CSS แล้วแสดงผลออกมา

Server

ตัว Live Server (Five Server) Extension ใน VS Code ทำหน้าที่เป็นเซิร์ฟเวอร์จำลองในเครื่อง คอยส่งไฟล์เว็บไปให้เบราว์เซอร์เปิดดูครับ

How I Built

เว็บนี้ผมเริ่มทำตั้งแต่ศูนย์ โดยแบ่งขั้นตอนการทำออกเป็น 3 สเต็ปหลักๆ ครับ:

ขั้นตอนแรก (วางโครงสร้าง)

ใช้ HTML วางโครงของหน้าเว็บทั้งหมดก่อน แบ่งเป็นส่วน header, nav และ section ต่างๆ

ขั้นตอนที่สอง (ตกแต่งหน้าตา)

ใช้ CSS มาจัดสไตล์ คุมโทนสีชมพูขาว และปรับแต่งฟอนต์กับระยะห่างให้อ่านง่าย

ขั้นตอนสุดท้าย (ทดสอบและแก้ไข)

ใช้ Live Server เปิดพรีวิวดูหน้าตาเว็บแบบเรียลไทม์ แล้วคอยไล่แก้บั๊กการจัดวาง layout ต่างๆ

เครื่องมือและแหล่งข้อมูลที่ใช้ช่วยเรียนรู้

  • โปรแกรมและเครื่องมือ: ใช้ VS Code ในการเขียนโค้ดทั้งหมด ร่วมกับ Extension อย่าง Live Server เพื่อรันเซิร์ฟเวอร์จำลองดูหน้าเว็บ
  • แหล่งข้อมูล: ศึกษาแท็ก HTML และคุณสมบัติ CSS พื้นฐานจากสไลด์ประกอบการสอนของวิชา CS100, เว็บไซต์ W3Schools และค้นหาเทคนิคการจัด layout เพิ่มเติมจากอินเทอร์เน็ตครับ
